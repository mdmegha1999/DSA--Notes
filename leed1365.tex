
// 1365. How Many Numbers Are Smaller Than the Current Number

✅ QUESTION KA SIMPLE MEANING

Hume ek array diya hai:
nums = [8, 1, 2, 2, 3]

Har number ke liye hume check karna hai:

👉 Is number se chhote kitne numbers array me present hain?
Aur uska count output me store karna hai.

🔍 Let’s understand with example
⭐ nums = [8, 1, 2, 2, 3]
For 8:

Isse chhote numbers:
→ 1, 2, 2, 3
Count = 4

For 1:

Isse chhota number koi nahi
Count = 0

For 2 (first 2):

Isse chhota:
→ 1
Count = 1

For 2 (second 2):

Same logic
Count = 1

For 3:

Isse chhote:
→ 1, 2, 2
Count = 3

⭐ Final Output:
[4, 0, 1, 1, 3]

🧠 Question ka logic

Har number ke liye hume do cheeze dekhni hain:

1️⃣ Array ke saare elements loop karna
2️⃣ Compare karna:

nums[j] < nums[i]


Agar chhota ho → count++

📌 VERY SIMPLE DIAGRAM
i = 0 → nums[i] = 8
Check all elements:
1 < 8  → count = 1
2 < 8  → count = 2
2 < 8  → count = 3
3 < 8  → count = 4
Result = 4


Fir next number…

⭐ Brute Force Code (Easy Version – Interview Friendly)



var smallerNumbersThanCurrent = function(nums) {
    let result = [];

    for (let i = 0; i < nums.length; i++) {
        let count = 0;

        for (let j = 0; j < nums.length; j++) {
            if (nums[j] < nums[i]) {
                count++;
            }
        }

        result.push(count);
    }
    
    return result;
};
